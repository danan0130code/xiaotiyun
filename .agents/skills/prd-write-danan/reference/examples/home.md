## 1. 需求背景

### 1.1 功能定位
校体云 K12 教师端首页是老师进入应用后的主页面，提供各功能模块的快速入口和数据概览。

### 1.2 目标用户
- **体育老师**：查看所负责班级的学生体质健康数据和运动情况
- **班主任**：查看本班学生的整体运动参与情况
- **学校管理员**：查看全校运动数据概览

### 1.3 核心场景
1. 老师进入应用，快速查看所负责班级的体测数据
2. 老师从首页入口进入排行榜，查看学生排名情况
3. 老师从首页入口进入活动管理，创建或查看校园活动

---

## 2. 页面模块

### 2.1 体质健康模块

| 入口名称 | 说明 | 跳转目标 |

| 体测数据 | 查看学生体测成绩 | 体测数据详情页 |

### 2.2 日常锻炼模块

| 入口名称 | 说明 | 跳转目标 |
|----------|------|----------|

| 运动数据 | 查看运动统计 | 运动数据页面 |
| 运动明细 | 查看详细记录 | 运动明细列表 |
| 阳光跑 | 阳光跑步活动 | 阳光跑页面 |
| 校园活动 | 查看/创建活动 | 校园活动列表 |

### 2.3 教学教务模块

| 入口名称 | 说明 | 跳转目标 |
