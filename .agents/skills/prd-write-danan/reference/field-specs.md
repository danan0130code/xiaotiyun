# 字段说明规范

## 1. 展示字段 4 要素

展示字段必须包含以下 4 个要素：

| 要素 | 说明 | 是否必填 |
|------|------|---------|
| 计算公式 | 怎么算出来的 | ✅ |
| 取值规则 | 从哪取数据 | ✅ |
| 格式 | 保留几位、什么单位 | ✅ |
| 边界情况 | 无数据怎么处理 | ✅ |

### 示例

**✅ 好的示例**：
```
有记录学生数÷班级总人数；格式：百分比，0 位小数；无数据时显示"--"
```

**❌ 坏的示例**：
```
班级参与率（缺少计算逻辑和边界情况）
```

### 完整表格示例

| 字段 | 类型 | 说明 |
|------|------|------|
| 参与率 | 展示 | 有记录学生数÷班级总人数；格式：百分比，0 位小数；无数据时显示"--" |
| 平均成绩 | 展示 | 所有学生成绩总和÷学生数；格式：1 位小数；无数据时显示"--" |

---

## 2. 编辑字段 5 要素

编辑字段必须包含以下 5 个要素：

| 要素 | 说明 | 是否必填 |
|------|------|---------|
| 字段类型 | 输入框/下拉选择/单选/多选 | ✅ |
| 必填 | 是否必填 | ✅ |
| 输入限制 | 长度/格式/范围 | ✅ |
| 校验规则 | 什么情况下校验失败 | ✅ |
| 错误提示 | 校验失败时的提示文案 | ✅ |

### 表格格式

| 字段名称 | 字段类型 | 必填 | 是否可编辑 | 逻辑 | 错误提示 |
|---------|---------|------|-----------|------|---------|
| 活动名称 | 输入框 | ✅ | 是 | 2-50 字符；不能为空；长度超限 | 1. 未输入：请输入活动名称<br>2. 长度超限：活动名称长度不能超过 50 个字符 |
| 学籍号 | 输入框 | ✅ | 否 | 唯一；1-30 字符；数字 + 字母 | 1. 未输入：学籍号不能为空<br>2. 已存在：学籍号已存在<br>3. 长度超限：最长 30 个字符<br>4. 格式错误：只能输入数字和字母 |

---

## 3. 错误提示三要素

错误提示必须包含：

1. **定位**：第几行、哪个字段
2. **问题**：什么错了
3. **解决方案**：正确示例

### 示例

```markdown
第 X 行【运动日期】格式错误，请使用"2026-04-10"或"2026/04/10"格式
```

---

## 4. 错误提示书写规范

- 分情况列出，每种情况一行
- 格式：`1. 情况：提示文案`

### 典型示例

| 字段 | 错误提示 |
|------|---------|
| 学生姓名 | 1. 未输入：学生姓名不能为空<br>2. 长度超限：学生姓名长度不能超过 20 个字符 |
| 学籍号 | 1. 未输入：学籍号不能为空<br>2. 已存在：学籍号已存在<br>3. 长度超限：最长 30 个字符<br>4. 格式错误：只能输入数字和字母 |
| 手机号 | 1. 未输入：手机号不能为空<br>2. 格式错误：请输入正确的手机号<br>3. 已存在：手机号已注册 |
| 活动时间 | 1. 未选择：请选择活动时间<br>2. 时间冲突：该时间段已存在活动 |

---

## 5. 计算逻辑写法

计算逻辑必须包含：

- 计算公式：怎么算出来的
- 取值规则：从哪取数据
- 格式：保留几位小数、什么单位
- 边界情况：无数据时怎么处理

### 完整示例

```markdown
本月有生成运动记录的学生数 ÷ 班级总人数；格式：百分比，0 位小数；
和选择的运动项目、场景都没关系，统计的是所有运动的参与情况；
无数据时显示"--"
```

---

## 6. 边界情况写法

| 场景 | 处理方式 |
|------|----------|
| 无数据 | 显示"--"或"0%"或隐藏模块 |
| 分母为 0 | 显示"--" |
| 数据异常 | 显示"--"或提示"数据异常" |

### 表格示例

| 场景 | 处理方式 | 提示文案 |
|------|----------|----------|
| 网络异常 | 显示重试按钮 | "网络异常，请检查网络后重试" |
| 无数据 | 显示"--" | - |
| 数据加载失败 | 显示刷新按钮 | "数据加载失败，请点击刷新" |
| 权限不足 | 隐藏模块或显示无权限提示 | "您暂无权限查看此内容" |
