# 硬件设备模块详情

**最后更新：** 2026-04-28
**用途：** 体锻小站、LED大屏、3588 智慧体育盒子、体质测量设备功能清单

---

## 一、体锻小站

**定位：** 简化版一体机，横屏 16:9 安卓设备，3588 芯片，相机和算力盒外接
**交互方式：** 手势识别
- 举手 → 进入选择运动
- 左右手侧平举 → 切换运动项目
- 举手 → 开启运动项目

**模块列表：**

| 模块 | 功能 | 现状描述 |
|------|------|----------|
| 跳绳 | 5 人同时 | 支持多人检测 |
| 立定跳远 | 1 人 | 垫步/单脚跳违规检测 |
| 仰卧起坐 | 2 人 | - |
| 俯卧撑 | 2 人 | - |
| 趣味运动 | 5 人 | 开合跳、深蹲、单脚跳、深蹲跳、高抬腿、双脚左右跳 |
| 活力跳跳 | 4 人 | 吃金币游戏 |
| 青蛙跳 | 待补充 | 新增运动项目 |

## 二、LED大屏

**定位：** 横屏 16:9 安卓设备，3568 芯片
**日常用途：** 数据驾驶舱（汇总 AI 体育设备运动数据）
**运动时用途：** 实时数据投屏
**学生用途：** 扫脸查看个人运动记录

**模块列表：**

| 模块 | 功能 | 现状描述 |
|------|------|----------|
| 数据驾驶舱 | 班级排名、阳光跑榜单、成绩排名、今日明星榜 | 日常展示 |
| 实时投屏 | 长跑/阳光跑/短跑/跳绳实时数据 | 运动时投屏 |
| 扫脸查看 | 个人运动记录 | 学生扫脸查看 |
| 宣传轮播 | 图片/视频轮播 | 支持定时开关机 |

## 三、3588 智慧体育盒子

**定位：** 无屏安卓盒，边缘计算设备
**支持业务：** 长跑、短跑、K12 阳光跑、高校校园跑
**操作方式：** 无屏幕不可触摸，通过教师小程序（K12）远程控制（选人、发令、看成绩）

**模块列表：**

| 模块 | 功能 | 现状描述 |
|------|------|----------|
| 点位抓拍 | 接收摄像头数据 | 接收 1-2 个摄像头抓拍数据 |
| 成绩计算 | 距离/配速/有效性 | 配速校验 2-10 秒/米（可配置） |
| LED 推送 | 推送数据到 LED | 批量刷新 500ms，每点位独立队列 |
| 成绩上传 | 上传云端 | 超时无数据（10 分钟，可配置）后生成记录上传 |

**校园跑规则：**

| 规则 | 说明 |
|------|------|
| 配速校验 | 2-10 秒/米（学校可调整） |
| 超时判定 | 10 分钟无抓拍（学校可调整） |
| 跨天处理 | 不跨天，算两条记录 |
| 照片去重 | 第 1 点位取最晚，后续取最早 |
| LED 推送 | 批量刷新 500ms，每点位独立队列 |

## 四、体质测量设备

**定位：** 身高体重、肺活量、握力测量，5 人同时

| 模块 | 功能 | 现状描述 |
|------|------|----------|
| 身高体重 | 测量 | 5 人同时 |
| 肺活量 | 测量 | 5 人同时 |
| 握力 | 测量 | 5 人同时 |

| 项目 | 单位 | 小数位 |
|------|------|--------|
| 身高 | 厘米 | 1 位小数 |
| 体重 | 千克 | 2 位小数 |
| 肺活量 | 毫升 | 正整数 |
| 握力 | 千克 | 2 位小数 |
