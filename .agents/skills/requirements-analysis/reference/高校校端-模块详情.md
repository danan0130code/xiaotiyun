## 二、菜单结构

```
校端后台（高校版）
├── 基础管理                    ← 顶部 Tab
│   ├── 学校管理                /#/basic/school
│   ├── 校区管理                /#/basic/campus
│   ├── 学院管理                /#/basic/college
│   ├── 班级管理                /#/basic/class
│   ├── 学生管理                /#/basic/student
│   ├── 教师管理                /#/basic/teacher
│   ├── 学期管理                /#/basic/semester
│   ├── 权限管理                （侧栏但未见详情页）
│   ├── 设备管理                （侧栏但未见详情页）
│   └── 激活码管理              /#/basic/activateCode
├── 学生运动数据                ← 顶部 Tab
│   └── 学生运动记录            /#/athleticAata/studentSportsRecord
└── 阳光跑                      ← 顶部 Tab
    ├── 跑步成绩管理            /#/sunshineRun/scoreList
    ├── 规则设置                /#/sunshineRun/ruleSet
    ├── 学期目标管理            /#/sunshineRun/semesterGoals
    └── 申诉管理                /#/sunshineRun/appealApproval
```

## 六、K12 版 vs 高校版差异

| 功能 | K12 版 | 高校版 |
|------|--------|--------|
| 组织架构 | 学校→年级→班级 | 学校→校区→学院→班级 |
| 学生标识 | 学籍号 | 学号 |
| 校区管理 | ❌ | ✅ |
| 学院管理 | ❌ | ✅ |
| 激活码管理 | ✅（运维管理下） | ✅（基础管理下） |
| 评分标准管理 | ✅ | 未见此菜单 |
| 体质测试 | ✅ | 未见此菜单 |
| 教学管理 | ✅ | 无 |
| 课后作业 | ✅ | 无 |
| 金币系统 | ✅ | 无 |
| 驾驶舱 | ✅ | 无 |
| 跑步功能 | 阳光跑管理（一体机） | 阳光跑（3588盒子） |
