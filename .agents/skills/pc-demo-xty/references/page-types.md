# 页面类型规范

## 占位页面（Phase 1）

初版只做菜单导航，页面内容为占位：

```jsx
// pages/Basic/Student/index.jsx
import Placeholder from '../../../components/Placeholder'

export default function Page() {
  return <Placeholder name="学生管理" />
}
```

Placeholder 组件展示图标 + 页面名称，居中对齐。

---

## 列表页（Phase 2+）

后续填充内容时，列表页结构从上到下为：

```
┌─────────────────────────────────────────┐
│  页面标题（16px，字重 500）               │
├─────────────────────────────────────────┤
│  筛选区（常用筛选 + "查询"/"重置"）        │
├─────────────────────────────────────────┤
│  操作按钮区（新增、批量导入、导出等）       │
├─────────────────────────────────────────┤
│  列表区（antd Table，表头固定）            │
│  ...                                     │
├─────────────────────────────────────────┤
│  分页组件（右对齐，默认20条/页）            │
└─────────────────────────────────────────┘
```

### 筛选区

- 常用筛选项一行展示（3-5 个），antd `Form` 布局
- "查询"和"重置"按钮
- 复杂筛选用 `Modal` 弹窗

### 操作按钮区

- 按钮靠左，主操作用 `type="primary"`
- 常见：新增、批量导入、导出 Excel

### 列表区

- antd `Table`，行选择 checkbox
- 操作列在右侧，`Space` 排列文字链接
- 表头浅灰背景

### 分页

- antd `Pagination`，默认 20 条/页，可选 10/20/50
- Mock 数据 100 条

## 看板页（驾驶舱）

```
┌─────────────────────────────────────────┐
│  筛选条件（运动项目、时间范围）             │
├────────┬────────┬────────┬─────────────┤
│ 班级数  │ 教师数  │ 学生数  │ 运动总时长   │  ← 统计卡片
├────────┴────────┴────────┴─────────────┤
│                                         │
│  图表区（各班运动时长/次数、运动TOP榜等）    │
│                                         │
└─────────────────────────────────────────┘
```

- 使用 antd `Card` + `Statistic` 展示关键指标
- 图表使用 antd 内置图表或预留位置

---

## 详情/表单页

根据实际业务灵活开发：

- **详情页**：`Descriptions` 基本信息 + `Tabs` 多维度信息
- **表单页**：`Form` + `Modal` 弹窗表单
