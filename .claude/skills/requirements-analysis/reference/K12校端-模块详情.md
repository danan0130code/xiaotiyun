## 三、页面详情

### 3.1 学校管理

**路径：** `/#/foundation/school`

**列表字段：**
学校名称 / 学校编号 / 地区 / 类型 / 状态 / 有效截止日期 / 是否开启视频打卡 / 学生绑定登录率 / 班级数量 / 教师数量 / 学生数量

**筛选条件：**
学校类型（全部/小学/初中/高中）/ 地区 / 督学责任区 / 视频打卡 / 状态（全部/有效/已到期）/ 学校名称 / 有效截止日期

**操作：** 添加学校 / 导入学校 / 升年级设置 / 详情 / 编辑 / 删除
