# 一体机管理平台模块详情

**最后更新：** 2026-04-28
**用途：** 一体机管理平台菜单结构、设备管理功能

---

## 一、产品概述

**登录地址：** https://ytj-admin.xiaoti.cloud/#/auth/login
**定位：** 云端后台，设备配置与管理层。K12/高校平台通过 API 调用一体机管理平台

**平台定位说明：**

| 维度 | 一体机管理平台 | K12/高校平台 |
|------|---------------|-------------|
| 定位 | 设备管理层 | 业务层 |
| 功能 | 设备配置、抓拍、照片处理、成绩匹配 | 学生管理、成绩展示、数据分析 |
| 通信 | 提供 API | 调用 API |

---

## 二、菜单结构

```
一体机管理平台
├── 设备列表              ← 列表页，支持按设备类型筛选
├── 主控设备管理
├── 固件包管理
└── 通用设置

顶部 Tab：
├── 运维管理
├── 用户管理
└── 菜单管理
```

---

## 三、设备类型筛选

设备列表页支持按以下类型筛选：
一体机(1代) / 一体机(2代) / AI体锻小站(1代) / AI体锻小站(2代) / 智慧体育盒子 / 体质测量设备 / 体检一体机 / 坐位体前屈 / LED大屏

---

## 四、设备操作

每条设备记录支持：查看详情 / 获取日志 / 日志下载 / 设备删除 / 获取业务日志

**设备列表显示字段：**
设备名称 / 在线状态 / 内存已使用 / 摄像头状态 / 开启的项目 / 设备型号 / 序列号 / 设备ID / 激活日期 / 最后心跳
