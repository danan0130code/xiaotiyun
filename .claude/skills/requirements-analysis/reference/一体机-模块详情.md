# 一体机模块详情

**最后更新：** 2026-04-28
**用途：** 一体机（1 代 / 2 代）完整模块列表、成绩计算规则、配置规则

---

## 一、产品概述

**定位：** 自助体测终端，32 寸（2 代）/ 21 寸（1 代）触屏，安卓设备，集成相机 + 3588 芯片 + 算力盒
**部署场景：** 学校操场、体育馆、体测室
**支持模式：** 游客模式、自由训练、随堂测试、串班训练、体质测试、阳光跑
**运动项目：** 15+ 项（基础体测、跑步类、球类、趣味运动、体质测量）
**扩展位：** 最多 5 个扩展位（跳绳、仰卧起坐、引体向上、立定跳远、足球绕杆、实心球等）

## 三、长跑成绩计算规则

| 规则 | 说明 |
|------|------|
| 应跑圈数 | 跑步距离 ÷ 跑道长度 |
| 正常判定 | 照片数 ≥ 应跑圈数 |
| 异常判定 | 照片数 < 应跑圈数，需手动补图 |
| 手动补图 | 补图后重新计算成绩，照片锁定，保留 30 天 |
| 套发逻辑 | 每组最多 50 人，最多 3 组（150 人） |
| 多相机（2 代） | 最多 4 台外接摄像头，10 秒去重，取最早抓拍 |
| 人脸识别 | 相似度 ≥ 70% 认定 |

---

## 四、短跑成绩计算规则

| 规则 | 说明 |
|------|------|
| 冲线检测 | 冲线即记录成绩 |
| 结束条件 | 全部出成绩或倒计时结束（200米内 1 分钟，200 米以上 5 分钟） |
| 串道 | 冲线跑道≠分配跑道→打"串道"标识 |
| 相机配置 | 支持 2 台相机，可配置跑道对应关系 |
| 终点人脸识别（2 代） | 可选开启，建模异常弹窗提示 |
| 待选池 | 30 天自动清理 |

## 五、关键配置规则

### 5.1 长跑配置

| 配置项 | 默认值 |
|--------|--------|
| 套发 | 每组最多 50 人，最多 3 组（150 人） |
| 成绩计算 | 照片数 ≥ 应跑圈数=正常；< 应跑圈数=异常 |
| 人脸识别 | 相似度 ≥ 70% 认定 |
| 手动补图 | 异常成绩可手动选图，照片锁定，保留 30 天 |
| 多相机（2 代） | 最多 4 台，10 秒去重，取最早 |

### 5.2 短跑配置

| 配置项 | 说明 |
|--------|------|
| 同时人数 | 1-8 人（8 跑道） |
| 串道 | 冲线跑道≠分配跑道→打"串道"标识 |
| 相机配置 | 支持 2 台，可配置跑道对应关系 |
| 终点人脸识别（2 代） | 可选开启，建模异常弹窗提示 |
| 待选池 | 30 天自动清理 |
