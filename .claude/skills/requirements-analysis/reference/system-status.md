## 二、系统现状详述

### 2.1 一体机（1 代 / 2 代）

**部署场景：** 学校操场、体育馆、体测室
**支持模式：** 游客模式、自由训练、随堂测试、串班训练、体质测试、阳光跑

| 模块 | 页面/功能 | 核心功能 |
|------|-----------|----------|
| 首页 | 模式选择 | 按运动模式分类选择，单项目直接显示项目名称 |
| 首页 | 排行榜 | 同类别运动合并排行榜 |
| 登录 | 人脸识别 | 人脸建模，相似度判定 ≥ 70% |
| AI 识别 | 动作识别 | AI 动作计数、违规检测、实时成绩展示 |
| 基础体测 | 跳绳 | 1-5 人同时，无绳空跳检测 |
| 基础体测 | 立定跳远 | 1 人，垫步/单脚跳违规检测 |
| 基础体测 | 引体向上 | 1-2 人，双手未伸直检测 |
| 基础体测 | 仰卧起坐 | 1-2 人 |
| 基础体测 | 俯卧撑 | 1-2 人 |
| 跑步 | 短跑 | 50/100 米等，1-8 人 8 跑道，二段式/三段式/手动发令 |
| 跑步 | 长跑 | 800/1000 米等，套发逻辑（每组≤50人，最多 3 组=150 人） |
| 跑步 | 串道识别 | 冲线跑道≠分配跑道时打"串道"标识 |
| 跑步 | 相机配置 | 支持 2 台相机，可配置摄像头 - 跑道映射 |
| 跑步 | 终点人脸识别 | 可选开启，建模异常弹窗提示（仅 2 代） |
| 跑步 | 多相机抓拍 | 支持最多 4 台外接摄像头，10 秒去重取最早（仅 2 代） |
| 跑步 | 待选池 | 未匹配成绩 + 图片放入待选池，本地保留 30 天 |
| 跑步 | 手动匹配 | 老师屏幕手动选图匹配成绩 |
| 球类 | 排球/足球/篮球/实心球 | 1 人或 1 男 1 女 |
| 趣味运动 | 开合跳/深蹲等 | 5 人同时 |
| 体质测量 | 身高体重/肺活量/握力 | 5 人同时异步测试 |

**长跑成绩计算：** 应跑圈数=跑步距离÷跑道长度；照片数≥应跑圈数为正常，否则异常需手动补图，补图后照片锁定保留 30 天。

**短跑成绩计算：** 冲线检测即记录成绩，结束条件为全部出成绩或倒计时结束（200 米内 1 分钟，200 米以上 5 分钟）。
