# 高校 H5 学生端模块详情

**最后更新：** 2026-04-28
**用途：** H5 学生端（高校版）功能清单

---

## 一、产品概述

**状态：** 已发布
**登录方式：** 手机号 + 密码（2 步流程）
**当前版本：** 1.1.0

---

## 二、模块列表

| 模块 | 功能 | 现状描述 |
|------|------|----------|
| 注册 | 5 步流程 | 学校+学号→信息确认→手机号→验证码→密码 |
| 登录 | 手机号+密码 | 2 步流程，7 天登录态 |
| 忘记密码 | 手机号+验证码→重置密码 | - |
| 首页 | 个人信息/校园跑入口 | 学期切换/进度可视化/跑步日历 |
| 校园跑 | 运动记录列表/详情 | 日历/列表/分段详情/异常标记 |
| 申诉 | 选择申诉段/提交/列表/详情 | 异常数据申诉 |
| 个人中心 | 人脸照片/身份信息/联系方式/密码 | 人脸拍照自动上传 |
