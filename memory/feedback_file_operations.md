---
name: 文件操作注意事项
description: 操作含中文文件名/内容时的通配符和编码陷阱
type: feedback
---

**规则**：避免使用通配符操作重要文件，优先使用完整文件名或明确指定目标文件

**Why:** 在操作 `2.校体云K12教师端 - 排行榜 -PRD-v2.md` 时，`2*.md` 通配符匹配了多个文件（目标文件、.bak 备份、.new 中间文件），导致修改可能应用到了错误的文件上。同时备份文件也用相同通配符匹配，造成混淆。

**How to apply:**
1. 能用完整文件名时就不要用通配符
2. 备份文件要放到其他目录或用不同命名规则（如加时间戳 `backup_原文件名_20260423`）
3. 操作含中文的文件时，优先用 Python 二进制模式 (`rb`/`wb`) 直接操作 bytes，比字符串替换更可靠
4. 修改后立即用相同方式读取验证关键内容
5. 失败后清理中间文件（.new、.tmp、.bak 等），不要让临时文件残留在目录中
